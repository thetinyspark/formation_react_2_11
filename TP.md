TP n°12

Dans le fichier catalog.jsx, au sein du useMemo, il existe tout un bout de code 
permettant de filtrer les produits en fonction de paramètres précis (nom, prix min, prix max, plateformes). 

- Créez une fonction pour chaque type de filtre, au sein de CatalogUtils.js
- Puis créez une fonction globale à laquelle vous enverrez l'intégralité des paramètres
( et cette fonction globale appelera les autres fonctions)
- Faites-en sorte de créer toutes ces fonctions en mode TDD ( Test Driven Development )

- Et bien sur, une fois ces fonctions créées, utilisez-les au sein du useMemo.
